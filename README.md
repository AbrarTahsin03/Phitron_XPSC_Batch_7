# Phitron XPSC Batch 7

All the code from my Phitron XPSC (Batch 7) journey — the four course modules plus my weekly problem-set solutions.

## Course modules

| # | Course | Topics | Modules | Files |
|---|---|---|---|---|
| 1 | [Introduction to Programming](01-Introduction-to-Programming) | C basics: I/O, conditions, loops, arrays, strings, functions, pointers, recursion, structs | 15 | 93 |
| 2 | [C++ for DSA](02-CPP-for-DSA) | Dynamic memory, classes & objects, strings, sorting | 7 | 46 |
| 3 | [Basic Data Structures](03-Basic-Data-Structures) | Linked lists, stacks, queues, trees, heaps, maps/sets | 18 | 100 |
| 4 | [Introduction to Algorithms](04-Introduction-to-Algorithms) | Graphs (BFS/DFS, shortest paths, DSU, MST) and dynamic programming | 18 | 64 |
